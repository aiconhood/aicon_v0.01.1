AICON Documentation

AICON is a non-custodial swap router built on Robinhood Chain. This page covers how it works, how it's built, and how to integrate it.

Overview

Robinhood Chain launched with multiple DEXs live from day one, and more routing partners have joined since. Liquidity for any given pair is now spread across several venues, which means no single pool reliably has the best price.

AICON solves that by sitting on top of the chain's DEXs rather than competing with them. It holds no liquidity of its own. Instead, it checks quotes from the DEXs available on Robinhood Chain and routes each swap through whichever pool gives the best output at that moment.

Not affiliated with Robinhood. AICON is an independent third-party application built on Robinhood Chain. It has no relationship with Robinhood Markets, Inc.

How it works

  1. Connect. Connect a JSON-RPC compatible wallet. AICON prompts the user to add Robinhood Chain if it isn't already configured.
  2. Quote. AICON queries the on-chain quoters of each integrated DEX for the requested pair and amount.
  3. Compare. The quotes are compared after estimated gas, and the best net output is selected.
  4. Execute. A single transaction sends the swap through the chosen DEX's router contract. Funds move directly from the user's wallet to the pool and back — AICON's contract never holds a balance between steps.

Architecture

AICON has three moving parts:

LayerRole
Router contractA thin on-chain contract that forwards calls to the chosen DEX's router and enforces the user's minimum output.
Quote engineOff-chain service that queries each integrated DEX's quoter and ranks results before a swap is submitted.
FrontendWallet connection, quote display, and swap confirmation UI.

The router never becomes an intermediary for custody — it only ever forwards a call in the same transaction the user signs.

Smart contracts

The core contract is a minimal swap router. It does not manage liquidity, mint any token, or take custody of funds outside a single atomic transaction.

function swapExactTokensForTokens(
    address tokenIn,
    address tokenOut,
    uint256 amountIn,
    uint256 minAmountOut,
    address dexTarget,
    bytes calldata routeData
) external returns (uint256 amountOut);

Key properties:

  • minAmountOut is enforced on-chain — the transaction reverts rather than executing at a worse price.
  • dexTarget points to the specific DEX router selected by the quote engine for this trade.
  • The contract is guarded against reentrancy and can be paused in an emergency by the deployer address.
  • Native ETH swaps are wrapped and unwrapped automatically against WETH.

Contract addresses will be published here and pinned on GitHub once audited and deployed to mainnet.

Integration guide

Other apps on Robinhood Chain can route swaps through AICON directly.

1. Get a quote

const quote = await aicon.getQuote({
  tokenIn: "0x...",
  tokenOut: "0x...",
  amountIn: "1000000000000000000"
});

2. Build the transaction

const tx = await aicon.buildSwapTx({
  quoteId: quote.id,
  slippageBps: 50 // 0.5%
});

3. Send it

const receipt = await wallet.sendTransaction(tx);

Full SDK reference and example repo will live at github.com/aiconhood.

Security & non-custody

AICON is built around one rule: user funds never rest in an AICON-controlled address between the start and end of a swap.

  • Every swap is a single atomic transaction. It either completes at or above the user's accepted minimum output, or it reverts entirely.
  • The router contract holds no liquidity and has no admin function that can move user funds.
  • Token approvals are scoped to the router contract only, and can be revoked at any time through standard wallet tooling.
  • The contract will go through an independent audit before mainnet funds are routed through it at scale.

Supported assets

AICON routes any ERC-20 pair with active liquidity on an integrated DEX, including Robinhood Chain's tokenized stock assets. Because tokenized stocks trade continuously on a chain that settles against markets that aren't always open, quotes for these pairs may carry wider spreads outside of traditional market hours — the quote engine surfaces this rather than hiding it.

FAQ

Is there an AICON token?

No. AICON is a tool, not a token launch.

Does AICON charge a fee?

No platform fee is charged on swaps routed through AICON.

Is AICON affiliated with Robinhood?

No. AICON is an independent third-party application built on Robinhood Chain, with no affiliation to Robinhood Markets, Inc.
